# Revenue — Professional Animated React Website

Premium marketing agency website built with React + Vite.

## Included

- Cinematic loading/preloader animation
- Chess-based premium hero section
- Dark / light theme with localStorage memory
- UZ / RU language switch
- Custom cursor and magnetic buttons
- Hero mouse parallax
- Scroll progress indicator
- Animated metrics and marquee
- Spotlight + 3D service cards
- Animated project showcase
- Sticky process timeline
- Responsive mobile fullscreen menu
- Telegram lead form flow
- Reduced-motion accessibility support
- Production-ready `dist` build

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Deploy the `dist` folder or connect the project to Vercel/Netlify.

## Important

The result figures in the hero are demo numbers. Replace them with real Revenue case-study data before public launch.
